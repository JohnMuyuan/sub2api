# 账号只读

管理员在「用户管理」中新建或编辑用户，将角色选择为「账号只读」，并选择允许查看的账号分组。未分配分组时不会显示任何账号。

该角色登录后进入「号池统计」，只能查看授权分组内账号的状态、已有额度快照，以及最近 1、7、30、90 天的账号汇总统计。账号修改、测试、刷新凭据、导出及其他管理接口均不可访问。

账号及分组名称中的邮箱由服务端替换为 `***`，完整邮箱、凭据、备注、代理信息、原始错误和逐用户请求记录不会下发。统计按整个账号汇总；跨组共享账号也显示其账号总量。Claude/Codex 额度来自已有快照，刷新页面不会主动查询上游；其他平台显示暂无快照。

「可查看的账号分组」只控制统计可见范围，API 调用权限仍由原有消费分组单独管理。现有「观察者」角色保持原有权限。
