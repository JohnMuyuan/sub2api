# 账号只读

管理员在「用户管理」中新建或编辑用户，将角色选择为「账号只读」，并选择允许查看的账号分组。未分配分组时不会显示任何账号。

该角色本身是普通用户：可以使用仪表盘、API 密钥、用量、订阅等全部用户功能。在此基础上，侧边栏多出「账号管理」，进入与「观察者」相同的账号列表页，但只读：

- 可查看：账号状态、调度状态、5 小时 / 周额度窗口（可手动刷新额度）、容量、今日统计、分组、优先级、上游声明倍率与余额、到期时间等。
- 可操作：测试连接、查看统计。
- 不可操作：新建、编辑、删除、复制、导入、导出账号，批量操作，切换调度，修改优先级，刷新令牌 / 重新授权，重置额度，清除限流或临时不可调度，定时测试，上游倍率探测等。

服务端按独立白名单授权（`AccountViewerRouteAllowed`，必须是观察者白名单的子集），前端隐藏对应按钮只是体验层。

隐私：账号名、分组名、凭据和 extra 中出现的邮箱由服务端替换为 `***`；备注、代理、敏感凭据、自定义 Base URL 和母账号邮箱不会下发。为防止通过搜索逐字探测被隐藏的邮箱，该角色不能使用账号搜索，仍可按平台、状态、类型、分组筛选。账号详情接口（含完整凭据）对该角色不可用，测试连接与统计直接使用已脱敏的列表数据。

后端模式下普通用户无法登录，但该角色仍保留完整的用户功能（API 密钥、用量、订阅等）和账号管理页；观察者在后端模式下仍只有账号管理和自己的用量。

「可查看的账号分组」只控制账号可见范围，API 调用权限仍由原有消费分组单独管理。「观察者」角色保持原有权限。
