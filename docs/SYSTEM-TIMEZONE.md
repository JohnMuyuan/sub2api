# 全站时区

入口：系统设置 → 站点设置 → 全站时区。填写 `Asia/Taipei`、`UTC` 等 IANA 时区名称，点击「单独保存全站时区」。留空恢复跟随容器的 `TZ`、`TIMEZONE` 或配置文件（原优先级不变）。数据库中的非空设置优先于启动环境。

保存后重启应用容器，并刷新浏览器页面。页面显示当前生效时区和待重启状态。采用重启生效，确保 Go 全局时区、所有 PostgreSQL 连接、定时任务和统计日期同时切换，避免运行中的请求混用时间边界。多个应用副本应全部重启。

使用记录的时间显示、日期筛选、日期快捷范围、统计默认时间和系统自然日/周额度边界均使用生效时区。切换可能改变当期日历额度窗口归属；已有使用记录保留原始时间点，查询时按新的时区归类。

订阅的日额度按系统日历日刷新，原有滚动 7 天/30 天周期仍按实际经过时长计算。Claude 等上游返回的重置时间以及账号显式配置的重置时区保持各自规则。账号固定日/周额度可选择「跟随全站时区」，未指定时区时也跟随全站；明确选择 UTC 的账号保留 UTC。账号请求时区设置独立。

该设置保存在数据库，因此包含在数据库备份中。不会修改宿主机时区。修改时区不会恢复已经删除的历史使用记录。
